API Reference

Package and runtime records are available through the HTTP API.

Registry API

Endpoints use the package ID assigned at upload.

MethodPathPurpose
POST/api/packagesUpload a wheel as multipart field file.
GET/api/packagesList registered packages.
GET/api/packages/{package_id}Read package metadata and current status.
GET/api/packages/{package_id}/inspectorRead the latest inspection record and file inventory.
POST/api/packages/{package_id}/inspectionRun a package inspection.
POST/api/packages/{package_id}/runtimeStart a runtime session.
GET/api/packages/{package_id}/runtime/logsRead saved session output for this package.

Records

Package and runtime records include package details and status.

Runtime records include saved output.
