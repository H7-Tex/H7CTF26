# ZOMBIE WORKER

Relay keeps field technicians moving between sites, including when a connection drops. A routine release has just reached your workspace. Review the job list, activity, and sync behavior while keeping the current page open.

Find out what Relay did with the telemetry drift report. Follow its normal report workflow and retrieve the completed field package.

The app is designed for Chromium and should be opened over HTTPS. Use DevTools' Application panel and Network panel as needed. The work order appears through the same job details used for ordinary field reports.

The completed field package reflects the report setting saved before the client update. If you need to revise that earlier setting, start a fresh Relay session.
