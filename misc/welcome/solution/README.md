# The Ledger Opens - solution

Welcome / sanity-check challenge, Discord-delivered.

At event kickoff the Herald bot posts the flag in the Discord #announcements channel:

    H7CTF{the_ledger_is_open_let_the_reckoning_begin}

Players read it there and submit it on the platform to confirm their setup and land on the board.
No instance, no handout - the flag lives on the platform (for submission) and is announced on Discord.
