# Sounding Line

`pwn` / `insane` / on-demand per-team instance (tcp) / 1000 pts / dynamic flag

Cistern-9 is a flooded salvage station you can only reach through a narrow text uplink to a battered ROV. The bulkheads stay sealed until the old trim regulator agrees the manifold is equalized, and past the central shaft a survey transponder waits for someone to tell it where the bottom is. Pilot the drone, settle the standoff, and reprogram the transponder.

See `writeup/README.md` for the intended path and the reference solve.
