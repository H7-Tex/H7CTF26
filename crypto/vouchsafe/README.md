# Vouchsafe

`crypto` / `hard` / on-demand per-team instance (http) / 500 pts / dynamic flag

H7 Passport is our passwordless SSO. Staff tap a passkey and they are in. The admin console behind it only opens for enterprise-attested authenticators, the corporate hardware the portal already trusts. Open the admin console.

See `writeup/README.md` for the intended path and the reference solve.
