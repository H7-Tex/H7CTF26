# Broken Telephone

`crypto` / `insane` / on-demand per-team instance (tcp) / 500 pts / dynamic flag

Two boxes in a Halcyon mesh have been muttering at each other for months in a firmware dialect no upstream library will speak. You have a tap on the wire between them. Make the gateway hand over what only an operator is meant to see. The gateway keeps a provisioning secret it hands out only to its own kind. The guest node on this link is not its own kind. You are the wire now, so start talking.

See `writeup/README.md` for the intended path and the reference solve.
