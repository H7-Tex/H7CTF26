# Dog Whistle

`hardware` / `insane` / on-demand per-team instance (tcp) / 500 pts / dynamic flag

Aria takes orders it can hear, and the equalizer is the only guard the vendor left you. Lately it keeps obeying instructions nobody in the room ever gave. Get it to give up the flag it keeps in firmware. The engineering channel is sealed off from the room, or so the datasheet swears. Reach it and read what the speaker is hiding.

See `writeup/README.md` for the intended path and the reference solve.

## Files
- `challenge/` : Makefile, entrypoint.sh, eq.cfg, src
- `handout/` : SPEC.md, aria, dog_whistle.zip, eq.cfg, reference_ping.wav
- `solution/` : README.md, solve.py
