# Afterglow

`hardware` / `hard` / on-demand per-team instance (http) / 500 pts / dynamic flag

A dead airport departure board came back from salvage with its controller flash still readable, so we dumped it. Boot the image and it comes up, flickers, and paints a crisp tag along the top calibration strip that reads the same on every board we have tried, which is exactly why it is not the one you want.

See `writeup/README.md` for the intended path and the reference solve.
